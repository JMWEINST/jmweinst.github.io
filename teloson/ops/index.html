Download key

The desk is downloaded through a Teloson function that holds a read-only GitHub token; clients never see it. Make a fine-grained token on github.com (Settings → Developer settings → Fine-grained tokens) with Contents: Read on JMWEINST/portfolio-trading-engine only, and paste it here. It is stored in the database, never in this page.

Until this is set the installer stops after the account check.
